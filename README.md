## 👋 About Me

🚀 **Software Engineer · Backend, AI & Cloud** with 3.5+ years of commercial experience building and running production systems end to end, from APIs and search infrastructure to Kubernetes deployments and LLM integrations.

💼 **Technical Expertise:**
- **Backend:** Java (Spring Boot, microservices), PHP (Laravel), Python (FastAPI), C# (ASP.NET / .NET)
- **Frontend:** React, Vue.js, Next.js, Angular, TypeScript
- **Mobile:** React Native, including offline-first apps
- **Data & Search:** Elasticsearch, PostgreSQL, MySQL, MariaDB, Redis
- **AI / LLM:** Claude, OpenAI, Gemini and Groq APIs, Ollama, Whisper, tool calling, structured outputs, PyTorch
- **DevOps:** Linux, Docker, Kubernetes, GitLab CI, GitHub Actions, Harbor, Traefik
- **Observability:** Grafana, Loki, Promtail, Sentry
- **Testing:** PHPUnit, Pest, PHPStan, JUnit

⚙️ **What I focus on:**
- Reliable integrations: retries with backoff, circuit breakers, idempotent imports
- Performance: fast search APIs and optimized data pipelines
- Safe delivery: CI security gates, automated tests and safeguards that stop mistakes before production
- Working daily with AI coding agents (Claude Code with custom skills and project conventions)

🌱 **Currently focused on:**
- Distributed systems and scalable backend architecture
- AI agents and LLM tooling for developers
- Cloud-native infrastructure and observability
